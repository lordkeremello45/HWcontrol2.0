SECURITY & TRUST

Transparent by design.

Trust the process, verify the files, and inspect the source.

01

Local-only bridge

The bridge is designed around loopback communication rather than unnecessary network exposure, with authenticated communication between components.

02

Release integrity

Release workflows publish SHA-256 checksums and GitHub artifact attestations where configured. Verify the checksum before installing a downloaded package.

03

Open source

Review the implementation, report vulnerabilities responsibly, and inspect the release workflow instead of relying on marketing claims.

04

Windows signing status

Windows binaries are currently unsigned unless a release is explicitly built with the project's signing secrets. An unsigned build will not carry a commercial publisher certificate.

# Technical References

The canonical consolidated source list is maintained in the repository at [docs/REFERENCES.md](https://github.com/lordkeremello45/HWcontrol2.0/blob/main/docs/REFERENCES.md).

This Wiki page is the short navigation copy used by the published project Wiki. It records the main research areas without implying that every referenced technology is implemented.

## Primary research areas

- **Windows:** Microsoft Learn, WMI, Windows services/LocalService, named pipes, WinVerifyTrust, MSIX and Microsoft Store.
- **Linux:** Linux kernel documentation, hwmon, block I/O statistics, fs-verity, Debian and Ubuntu.
- **macOS:** Apple Developer Documentation and Apple Platform Security.
- **Hardware vendors:** NVIDIA, AMD and Intel developer documentation.
- **Security:** NIST SSDF, CISA Secure by Design, OWASP, CWE, CVE/NVD and OpenSSF.
- **Supply chain:** GitHub Actions, CodeQL, Dependabot, SBOM formats, artifact attestations, Sigstore and SLSA.
- **Signing/distribution:** Authenticode, SignTool, Apple signing/notarization, SignPath, GitHub Releases and GitHub Pages.
- **Development:** Flutter, Dart, Go, Rust, C++, CMake, Ada and SPARK.
- **Licensing:** GPLv3, AGPLv3, Apache-2.0 and SPDX.
- **Infrastructure/community:** GitHub, GitLab, Codeberg, Stack Overflow, Google Developers and GitHub Sponsors.
- **Feedback automation:** Google Forms, Apps Script and GitHub REST API.

## Interpretation

References are design inputs and research sources. They are **not evidence that HWcontrol2.0 implements a feature**. Implementation status must be established from repository code, tests, CI results, packaged artifacts and real platform/hardware validation.

For the full URLs and HWcontrol-specific rationale, see the canonical [technical references](https://github.com/lordkeremello45/HWcontrol2.0/blob/main/docs/REFERENCES.md).

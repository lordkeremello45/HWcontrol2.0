# Troubleshooting — Windows

## Bridge offline

Check that the `HWControlBridge` service is installed and running.

Default endpoint:

```text
127.0.0.1:8080
```

## Missing telemetry

Check the installed GPU driver and sensor provider. Windows telemetry can use LibreHardwareMonitor WMI or a WMI fallback, so available fields can vary.

## Control command fails

The current bridge deliberately returns an error when the hardware-control backend is not available in the build. This is different from a UI error and is expected on builds without a control backend.

## Installation problems

Use the MSI install log generated by the CI smoke test pattern and verify that the downloaded release checksum matches the published SHA-256 file.

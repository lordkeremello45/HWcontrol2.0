# Support

## Before asking for help

Please check:

- the README;
- the project Wiki;
- the latest GitHub Release;
- existing GitHub Issues.

For installation or runtime problems, include:

- HWControl version;
- Windows, Linux, or macOS version;
- CPU/GPU model;
- architecture;
- relevant diagnostic output;
- exact error message.

Remove authentication keys, tokens, personal data, and other secrets before sharing logs.

## Hardware support

Hardware telemetry and control depend on the operating system, driver, firmware, permissions, and available sensor interfaces. A feature being visible in the dashboard does not mean that every hardware configuration supports it.

When reporting missing telemetry, provide the detected hardware and driver information if available.

## Security

For vulnerabilities, do not open a public issue. Use the repository's GitHub Security reporting mechanism described in [SECURITY.md](SECURITY.md).

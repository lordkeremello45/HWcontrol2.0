MEET PULSAR
============

Pulsar is the official visual mascot of HWcontrol2.0, an open-source desktop application for PC hardware monitoring and supported hardware control. The reference image supplied by the project owner defines Pulsar's canonical appearance.

CANONICAL APPEARANCE
-------------------
Pulsar is a clean, minimalist, four-point star with four broad, curved arms that taper to softly rounded tips. The silhouette is horizontally wide and vertically balanced, with smooth concave curves between the four points.

The body uses a vivid, continuous gradient:
- Cyan / turquoise around the upper point and left side
- Bright blue through the center-left
- Violet and purple through the lower region
- Magenta and pink toward the right-center
- Warm coral / orange at the right point

At the center is a bold white "> -" symbol: a greater-than sign followed by a short horizontal dash. Keep the symbol centered, crisp, and clearly legible.

The canonical presentation uses a near-black background, making the bright gradient and white symbol stand out. The star has no face, limbs, clothing, or extra decorative parts. Do not redesign Pulsar as a different star shape, add eyes, or change the central symbol when reproducing the official mascot.

IDENTITY AND ROLE
-----------------
Pulsar is the recognizable visual guide for the HWcontrol2.0 experience. It gives the project a modern, approachable identity while preserving a professional, technical feel. It may appear in onboarding, help pages, diagnostics, documentation, the website, and application branding.

Pulsar represents the user-facing identity of HWcontrol2.0. It does not replace the monitoring engine, Go Bridge, platform APIs, security checks, or test evidence.

PERSONALITY
-----------
Pulsar should feel calm, helpful, curious, and technically minded. The visual identity should remain simple, recognizable, and consistent across the project.

ACCESSIBILITY
-------------
Keep the central symbol and silhouette legible at small sizes. Use sufficient contrast. Never communicate a real system state using color or mascot appearance alone; pair status colors with clear text or accessible indicators.

VOICE
-----
Offline text-to-speech using Piper has been considered as part of the broader project experience. Voice support should only be described as available in a particular build when that build actually includes and enables it. Important information must remain available as text, and users should be able to control or disable spoken output.

SECURITY AND HONESTY
--------------------
Pulsar is a mascot, not a security authority. Its appearance must not imply that a system is safe, a threat has been detected, or a hardware operation succeeded unless the application has reliable evidence for that statement. Real status, warnings, and diagnostic results must come from the software's actual checks.

DESIGN RULES
------------
1. Treat the project owner's reference image as the canonical visual source.
2. Preserve the four-point curved silhouette, gradient direction, dark-background presentation, and white "> -" center symbol.
3. Keep the design minimal; do not add a face, limbs, or unrelated decoration.
4. Avoid distracting animation or effects that obscure telemetry, controls, or warnings.
5. Use clear text and accessible status indicators alongside any status-related visuals.
6. Do not use the mascot as proof that a feature is implemented, hardware is compatible, or a security check passed.

IN SHORT
--------
Pulsar is HWcontrol2.0's official four-point gradient-star mascot with a white "> -" symbol on a dark background. The supplied reference image defines its appearance; the mascot's purpose is to make the project recognizable and approachable without compromising technical accuracy, accessibility, or user trust.
